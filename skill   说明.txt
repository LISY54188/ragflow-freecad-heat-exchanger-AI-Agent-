/exchanger 自定义命令使用说明：



简介：
这是一个专为管壳式换热器全流程设计 + FreeCAD 参数化建模打造的 Claude Code 工作流命令。它会引导你完成设计计算、核验，并自动生成三维模型脚本。


前提环境：
使用本命令前，请确保以下环境已就绪：
操作系统：Windows 10/11，已启用 WSL
WSL 内安装 FreeCAD：推荐 0.19 或更高版本
守护进程：项目目录 /home/lisu/fc_daemon/fc_daemon_fixed.py 需存在并可运行（可忽略）
Windows 项目路径：C:\Users\你的用户名\Desktop\claude设计\ （可根据自己情况修改，但需要同步更新命令脚本中的路径）
Claude Code：已安装并可以正常使用（VS Code 扩展或命令行版均可）
如果你希望使用 RAGFlow 知识库或设计 Agent，还需要额外部署相关服务，但本命令在不依赖它们时也可直接使用内置设计逻辑。
必要的内容：请确保你已寻找并下载了对应的知识库（国标，换热器手册等等）

安装命令：
在项目根目录下创建 .claude/commands/ 文件夹（如果还没有）。
在 .claude/commands/ 中新建文件 exchanger.md。
将本说明文档末尾提供的完整命令内容（即你手中的 skill 文件）复制粘贴到 exchanger.md 中。
保存文件。
现在，在 Claude Code 会话中输入 /exchanger 即可激活该工作流。


使用流程：
激活后，Claude 会严格按照四步流程工作，不会跳过任何步骤：

设计计算与结果核验
首先会向你收集设计参数（功率、介质、温度、压力、结构形式等），然后输出固定格式的设计结果表，并请你逐项核对。

结构化零部件清单
生成 JSON 清单，列出所有零件的关键尺寸、约束关系和 FreeCAD 生成方法。

设计核验
自动检查配合自洽性（管板、筒体、折流板间隙等）和标准符合性（法兰、垫片），输出通过/警告/错误报告。若有错误，会暂停并等待你修正。

FreeCAD 建模
生成完整的 FreeCAD Python 脚本（兼容 0.19），通过 WSL 守护进程或一次性命令执行三维建模，并导出 STEP 文件。过程中还会进行每一步的坐标范围验证。

重要提示： 每一步的核验点都需要你确认后才会继续，务必认真核对设计数据，避免后期模型出错。


自定义路径与环境变量：
如果你不是使用原始路径，请修改以下内容：

命令文件 exchanger.md 内部：所有 /home/lisu/... 和 /mnt/c/Users/李素/... 等路径，需替换成你自己的 WSL 家目录和 Windows 桌面路径。
守护进程启动方式：如果你使用一次性建模模式，需修改 run_fc_build.bat 或命令中的脚本路径。

故障排除：
现象	                                  可能原因	                                         解决方法
/exchanger 无反应	 命令文件未正确放置或格式错误          	  检查 .claude/commands/exchanger.md 是否存在，内容是否完整
WSL 连接失败	         WSL 未启动或守护进程未运行	          在 PowerShell 中执行 wsl.exe --status，并重新启动守护进程
建模脚本报错	         路径中带中文或权限问题	                  将脚本复制到 /home/lisu/fc_daemon/ 下执行，避免中文路径
模型有明显错误	        违反了历史错误数据库中的典型 bug	  命令内置了自检机制，会尽可能避免，若仍出现，请反馈给维护者


开始使用：
在 Claude Code 中打开项目，输入：/exchanger
按照提示提供设计参数即可。
